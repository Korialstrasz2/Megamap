HARNESS LIMITS
This environment blocks file:// and localhost navigation. Browser workflows
therefore use an in-memory HTML page with local CSS/JS inlined and the CSP meta
tag removed. This verifies UI/logic, not actual navigation or CSP enforcement.
Native Windows BAT execution, the real local-file startup path, persistent
IndexedDB/localStorage recovery across restart, external VTT import, and
cross-browser compatibility were not tested. No soak-test or certified-native-
application claim is made. A navigation block is not silently counted as a
successful startup test.
